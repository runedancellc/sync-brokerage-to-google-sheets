sync-brokerage-to-google-sheets

TypeScript utilities for portfolio data syncing — reference implementation.

A collection of TypeScript modules for structuring, calculating, and formatting brokerage portfolio data for Google Sheets import.

Modules

Types

src/types.ts — Data models for holdings, accounts, portfolios.

interface Holding {
  symbol: string
  quantity: number
  price: number
  value: number
  costBasis: number
  gainLoss: number
  type: 'stock' | 'etf' | 'mutual_fund' | 'option' | 'crypto'
}

Calculations

src/calculations.ts — Portfolio analytics.

  • totalValue() — Aggregate portfolio value across all accounts
  • allocationByAsset() — Position-level allocation percentages
  • allocationByType() — Asset class breakdown (stock, etf, crypto…)
  • allocationByBroker() — Value distribution across brokerages
  • topHoldings() — Top N positions by value
  • diversificationScore() — Herfindahl–Hirschman concentration index

Formatters

src/formatters.ts — Spreadsheet-ready output.

  • portfolioToRows() — Flatten portfolio to sheet rows
  • toCsv() — Export as CSV
  • currencyFormat() / percentFormat() — Display helpers

Quick start

npm install
npx tsx examples/basic-portfolio.ts
